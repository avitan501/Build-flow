# Avantia Build

Dedicated source repository for `build.avantiap.com`.

## Ownership boundary

- The Vercel project and `avantiap.com` domain remain under the Avantia owner team.
- Developers manage this website through Git commits and pull requests.
- No domain transfer, Vercel team access, or DNS access is required.

## Deployment

Pushes to the production branch deploy through the connected Vercel project.
